📊 Project Insights

Dataset Overview
  • Total Tweets: 14,640
  • Airlines: US Airways, United, American, Southwest, Delta, Virgin America
  • Sentiment Categories: Positive, Neutral, Negative
  • Time Range: February 2015
Key Findings
  • 📉 56.6% of tweets express negative sentiment
  • 😊 16.7% show positive sentiment
  • 😐 26.7% are neutral
  • ⏰ Peak tweet activity between 6 PM - 10 PM

💡 How to Use the Dashboard

Dashboard Navigation
  1. Sentiment Distribution: Toggle between histogram and pie chart views
  2. Random Tweets: Select a sentiment to view random sample tweets
  3. Time Analysis: Use the slider to explore tweets by hour of day
  4. Airline Comparison: Select multiple airlines to compare their sentiment breakdown
  5. Word Clouds: Switch between positive, neutral, and negative to see common words
