Case Study: Pizza Sales Analysis Dashboard

Comprehensive pizza sales analysis dashboard built with SQL and Power BI. Total revenue of $817,860 across 21,350 orders with detailed insights into customer behavior, product performance, and sales trends.

Project Overview

This project involved creating a comprehensive pizza sales analytics dashboard using SQL for data extraction and Power BI for visualization. The analysis covered revenue performance, customer ordering patterns, product popularity, and time-based sales trends.

Key metrics revealed $817,860 total revenue from 21,350 orders, with an average order value of $38.31. The dashboard provides actionable insights for inventory management, marketing strategies, and operational optimization.

The Challenge

The pizza restaurant needed to understand:

  • Overall sales performance and revenue trends
  • Which pizza types and sizes generate the most revenue
  • Customer ordering patterns throughout different time periods
  • Top and bottom-performing products for inventory optimization
  • Sales distribution across different categories and sizes

The Approach & Solution

The solution combined SQL data analysis with Power BI visualization:

  • Data Extraction → Used SQL Server to query pizza sales database with complex aggregations
  • KPI Development → Created key performance indicators for revenue, orders, and customer metrics
  • Trend Analysis → Analyzed daily and monthly patterns using date functions
  • Dashboard Design → Built interactive Power BI dashboard with pizza-themed color palette

SQL Queries & Analysis

Here are the key SQL queries used to extract insights from the pizza sales data:

1. Key Performance Indicators (KPIs)
Total Revenue
SELECT 
    FORMAT(SUM(total_price), 'N2') AS Total_Revenue
FROM [Pizza Sales].[dbo].[pizza_sales];
Average Order Value
SELECT 
    Format(SUM(total_price) / COUNT(DISTINCT order_id), 'N2') AS Avg_order_Value 
FROM pizza_sales;
Total Pizza Sold
SELECT 
    SUM(quantity) AS Total_pizza_sold 
FROM pizza_sales;
Total Orders
SELECT 
    COUNT(DISTINCT order_id) AS Total_Orders 
FROM pizza_sales;
Average Pizzas per Order
SELECT 
    CAST(CAST(SUM(quantity) AS DECIMAL(10,2)) /
    CAST(COUNT(DISTINCT order_id) AS DECIMAL(10,2)) AS DECIMAL(10,2))
    AS Avg_Pizzas_per_order
FROM pizza_sales;
2. Daily and Monthly Trends
Daily Trends for Orders and Revenue
SELECT 
    DATENAME(WEEKDAY, order_date) AS order_day,
    COUNT(DISTINCT order_id) AS total_orders,
    Format(SUM(total_price), 'N2') AS total_revenue
FROM pizza_sales
GROUP BY DATENAME(WEEKDAY, order_date), DATEPART(WEEKDAY, order_date)
ORDER BY DATEPART(WEEKDAY, order_date);
Monthly Trends for Orders and Revenue
SELECT 
    DATENAME(MONTH, order_date) AS Month_Name,
    COUNT(DISTINCT order_id) AS total_orders,
    Format(SUM(total_price), 'N2') AS total_revenue
FROM pizza_sales
GROUP BY DATENAME(MONTH, order_date), DATEPART(MONTH, order_date)
ORDER BY DATEPART(MONTH, order_date);
3. Category and Size Analysis
Revenue Percentage by Pizza Category
SELECT 
    pizza_category, 
    CAST(SUM(total_price) AS DECIMAL(10,2)) as total_revenue,
    CAST(SUM(total_price) * 100 / (SELECT SUM(total_price) from pizza_sales) AS DECIMAL(10,2)) AS PCT
FROM pizza_sales
GROUP BY pizza_category;
Revenue Percentage by Pizza Size
SELECT 
    pizza_size, 
    CAST(SUM(total_price) AS DECIMAL(10,2)) as total_revenue,
    CAST(SUM(total_price) * 100 / (SELECT SUM(total_price) from pizza_sales) AS DECIMAL(10,2)) AS PCT
FROM pizza_sales
GROUP BY pizza_size
ORDER BY pizza_size;
4. Product Performance Analysis
Top 5 Pizzas by Revenue
SELECT TOP 5 
    pizza_name, 
    Format(SUM(total_price),'N2') AS Total_Revenue
FROM pizza_sales
GROUP BY pizza_name
ORDER BY Total_Revenue DESC;
Top 5 Pizzas by Quantity
SELECT TOP 5 
    pizza_name, 
    SUM(quantity) AS Total_Pizza_Sold
FROM pizza_sales
GROUP BY pizza_name
ORDER BY Total_Pizza_Sold DESC;
Top 5 Pizzas by Total Orders
SELECT TOP 5 
    pizza_name, 
    COUNT(DISTINCT order_id) AS Total_Orders
FROM pizza_sales
GROUP BY pizza_name
ORDER BY Total_Orders DESC;
