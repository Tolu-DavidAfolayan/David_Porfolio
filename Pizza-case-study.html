Project Overview

This comprehensive pizza sales analytics project leveraged SQL Server and Power BI to analyze 49,574 individual pizza sales and identify key business performance indicators. Using advanced SQL querying and interactive dashboard development, I created a complete business intelligence solution that provides actionable insights for restaurant management.

The analysis uncovered critical patterns in customer behavior, revealing that Classic pizzas drive 47% of total revenue while Friday consistently shows peak performance. This data-driven approach enables strategic decision-making for inventory optimization, staff scheduling, and marketing campaign targeting.

The Business Challenge

The pizza restaurant needed comprehensive insights into:

  • Revenue Performance: Total sales, average order values, and growth trends.
  • Product Analytics: Which pizza types and sizes generate the highest revenue.
  • Customer Patterns: Daily and monthly ordering behaviors and preferences.
  • Operational Insights: Peak hours, staff scheduling optimization, and inventory needs.
  • Category Analysis: Performance comparison across Classic, Supreme, Veggie, and Chicken categories.
  • Size Distribution: Revenue breakdown by Small, Medium, Large, and XL pizzas.

The Approach & Solution

I implemented a comprehensive SQL-driven analytics pipeline with interactive visualization:

1. Advanced SQL Analytics

  • Data Aggregation: Complex queries for KPIs, trends, and performance metrics.
  • Time-Series Analysis: Daily and monthly trend identification using date functions.
  • Product Performance: Top and bottom performers by revenue, quantity, and orders.
  • Statistical Analysis: Percentage calculations and ranking algorithms.

2. Interactive Dashboard Development

  • Power BI Integration: Connected SQL Server to Power BI for real-time visualization.
  • KPI Scorecards: Dynamic metrics with drill-down capabilities.
  • Trend Visualizations: Time-based charts showing daily and monthly patterns.
  • Category Analysis: Pie charts and bar graphs for product performance comparison.
Key Discovery

Classic category dominates with 47% revenue share! Thai Chicken Pizza leads individual performance while Large pizzas generate the highest per-unit revenue, revealing optimal product focus areas.

SQL Queries & Business Intelligence

Here are the key SQL queries that power the analytics dashboard:

1. Key Performance Indicators

Total Revenue Analysis
SELECT FORMAT(SUM(total_price), 'N2') AS Total_Revenue FROM [Pizza Sales].[dbo].[pizza_sales]; -- Result: $817,860.05
Average Order Value Calculation
SELECT Format(SUM(total_price) / COUNT(DISTINCT order_id), 'N2') AS Avg_order_Value FROM pizza_sales; -- Result: $38.31 average per order
Total Pizza Units Sold
SELECT SUM(quantity) AS Total_pizza_sold FROM pizza_sales; -- Result: 49,574 pizzas sold

2. Temporal Trend Analysis

Daily Performance Trends
SELECT DATENAME(WEEKDAY, order_date) AS order_day, COUNT(DISTINCT order_id) AS total_orders, Format(SUM(total_price), 'N2') AS total_revenue FROM pizza_sales GROUP BY DATENAME(WEEKDAY, order_date), DATEPART(WEEKDAY, order_date) ORDER BY DATEPART(WEEKDAY, order_date); -- Shows Friday as peak performance day
Monthly Revenue Patterns
SELECT DATENAME(MONTH, order_date) AS Month_Name, COUNT(DISTINCT order_id) AS total_orders, Format(SUM(total_price), 'N2') AS total_revenue FROM pizza_sales GROUP BY DATENAME(MONTH, order_date), DATEPART(MONTH, order_date) ORDER BY DATEPART(MONTH, order_date); -- July shows highest monthly performance

3. Product Performance Analytics

Top Revenue-Generating Pizzas
SELECT TOP 5 pizza_name, Format(SUM(total_price),'N2') AS Total_Revenue FROM pizza_sales GROUP BY pizza_name ORDER BY Total_Revenue DESC; -- Thai Chicken Pizza leads revenue generation
Category Revenue Distribution
SELECT pizza_category, CAST(SUM(total_price) AS DECIMAL(10,2)) as total_revenue, CAST(SUM(total_price) * 100 / (SELECT SUM(total_price) from pizza_sales) AS DECIMAL(10,2)) AS PCT FROM pizza_sales GROUP BY pizza_category; -- Classic category dominates with 47% market share
